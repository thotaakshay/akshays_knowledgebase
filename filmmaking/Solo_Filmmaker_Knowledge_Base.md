# 0. OPERATING CONTRACT FOR THIS FILE

This section controls how the knowledge base must be used and updated.

## 0.1 Canonical-source rule
Before giving production advice for a new reel, storyboard, self-shoot, dialogue scene, framing question, edit plan, CapCut construction, or post-shoot review, read this entire file first. Do not rely on a vague memory of it. The current contents of this file are the source of truth.

## 0.2 Mutable-truth rule
This file is not an append-only diary. If a rule is later proven wrong, incomplete, unsafe, impractical, or misleading:

1. Find the old rule in its actual section.
2. Replace or delete the wrong wording.
3. Add the corrected rule in the same logical place.
4. Add a short entry to the Change Log explaining what changed and why.
5. Do not leave two contradictory “current rules” active at the same time.

Historical mistakes may be preserved only inside the Evidence / Failure Log when they help explain how the corrected rule was discovered. They must be clearly labeled as superseded.

## 0.3 Evidence-before-rule rule
Do not convert every thought into a permanent rule immediately. Classify new information as one of:

- **Observed evidence:** what actually happened in a shoot/edit.
- **Working hypothesis:** what we currently think may solve it.
- **Verified rule:** tested enough to guide future production.
- **Personal rule:** specific to Akshay's body, face, performance, gear, workflow, or locations.
- **Open question:** still unresolved.

A hypothesis should become a verified rule only after practical evidence supports it.

## 0.4 Detail-preservation rule
Do not compress useful production learning into slogans. Keep the reasoning that makes the rule usable in the real world: what problem it solves, when it applies, when it does not apply, what to do step by step, and an example.

## 0.5 New-reel workflow rule
When Akshay brings a new reel idea, do not jump directly to “here are 10 shots.” Use this file to work backward from the finished edit. The planning sequence is:

**Idea / emotion → intended final edit → CapCut feasibility → edit map → directing → self-shooting logistics → performance/dialogue → sound → shoot order → edit → review → KB update.**

## 0.6 Tool constraint rule
Current default post-production assumption is **CapCut**, unless Akshay explicitly says he is using something else. A storyboard shot is not considered production-ready until we can explain how it will be assembled in CapCut with the tools and skill currently available.

## 0.7 Solo-creator rule
The system must assume that Akshay may need to do all of these alone:

- direct;
- frame the iPhone;
- lock focus/exposure/white balance;
- act;
- play multiple characters;
- remember or cue dialogue;
- maintain continuity;
- record sound;
- reset wardrobe/props;
- edit;
- review.

Advice that would be easy for a normal crew but impractical for one person must be translated into a solo-friendly method.

## 0.8 Adaptive teaching and visual-escalation rule
Do not assume that a technically correct explanation is learnable for Akshay simply because it is standard, complete, or easy for an expert to follow. Teaching must adapt to Akshay's actual responses in the moment.

Treat the following as signals that the current explanation method is not landing well enough:

- Akshay asks substantially the same concept again in different words;
- he can repeat terminology but cannot apply it to a scene or practical decision;
- he explicitly says the topic feels confusing, heavy, boring, or difficult to read;
- the concept depends strongly on spatial, visual, timing, movement, waveform, editing, lighting, or before/after comparison that is easier to perceive than to describe;
- a new concept depends on prerequisite ideas that have not yet become intuitive.

When one or more of these signals appears, do **not** simply repeat the same explanation with more terminology. Change the teaching representation. Use the following escalation order as appropriate:

1. Restate the idea in one plain sentence.
2. Use one concrete scene or real-world example that Akshay can imagine.
3. Compare the correct interpretation against one likely wrong interpretation.
4. Use a visual example, frame comparison, waveform, diagram, screen recording, professional-scene example, or short practical demonstration when the concept benefits from seeing it.
5. When useful, proactively search for a beginner-friendly YouTube/video explanation instead of waiting for Akshay to ask for one.
6. After the visual/video explanation, reconnect it to the exact filmmaking decision currently being learned and verify understanding with a small recall question or practical test.

### Video-selection difficulty gate
A video is not suitable merely because it is accurate or popular. Before recommending it, judge whether it matches Akshay's current level.

Prefer videos that:

- begin from intuition before advanced terminology;
- show the concept visually rather than relying mainly on lecture-style explanation;
- use examples close to the current filmmaking problem;
- explain one idea clearly before stacking several new ideas;
- do not assume technical knowledge that has not yet been learned;
- are engaging enough to function as a break from text-heavy study when boredom is becoming a learning barrier.

Reject or defer videos that are technically strong but start too far above the current learning level, move too quickly, depend on unexplained jargon, or introduce unnecessary complexity.

### Important constraint
Do not force video into every lesson. Text, conversation, practical experiments, and recall may be better when the idea is already clear. The rule is to **change representation when learning friction appears**, not to replace the entire learning process with videos.

# 1. CORE GOAL

The long-term goal is not merely to make individual reels. It is to make Akshay capable of repeatedly turning an imagined scene into a finished reel by himself.

The key success test is:

> **Can the final edit reproduce the intention that existed in the mind before shooting?**

A reel can look polished and still fail this test if it only happened by accident. A practice clip can look rough but still be valuable if it teaches a repeatable method. Over time, the goal is to reduce the difference between imagination and reproducible output.

# 2. WHY THIS KNOWLEDGE BASE WAS CREATED

## 2.1 Trigger event: failed two-character gym shoot
A short subconscious scene with two versions of the same person looked simple on paper. In practice, even a few seconds took roughly one and a half hours. The main problem was not laziness or giving up. The production generated too many simultaneous unresolved decisions:

- Where exactly should the iPhone be placed?
- How far should it be from the subject?
- Should the frame be wide, medium, close, or two-shot?
- How do two people appear to perceive each other correctly inside the frame?
- How are eyelines created when the second actor does not physically exist during the first pass?
- How should the 180-degree line be maintained?
- How should one person act both sides of a dialogue while remembering lines?
- How are pauses and reactions matched between separate performances?
- How can both characters appear in the same frame if desired?
- Can the imagined shot actually be built in CapCut?
- How does one judge their own face, body language, angle, posture, and expression while they are in front of the camera instead of behind it?
- How can sound practice be meaningful without usable visuals to attach the sound to?

The failure revealed a system problem: filmmaking skills were being learned too separately and the storyboard was being designed before the edit construction had been tested mentally.

## 2.2 Main realization
Filmmaking, editing, performance/self-shooting, and sound should develop together through small finished projects.

The core directional relationship is two-way:

### Direction A — Idea to camera
“I imagine this scene. What exact shots, performances, marks, camera positions, lighting, and takes are needed to capture it?”

### Direction B — Camera to edit
“If I capture those pieces, can CapCut actually reconstruct the scene I imagined?”

The director must understand both directions before production begins.

## 2.3 Current learning method — project-led, controlled experiments
The most useful learning pattern so far is not to finish a large cinematography curriculum before making reels. Learn one variable inside a small real scene, finish the edit, compare results, and carry only supported discoveries forward.

Use this loop when a skill is uncertain:

1. Design a tiny scene that isolates the uncertainty.
2. Keep unrelated variables as constant as practical.
3. Shoot enough handles and coverage to permit multiple edit choices.
4. Make controlled edit variants that change one decision at a time.
5. Compare the variants by what the audience receives, not by which one matches a textbook rule.
6. Record the result first as evidence; promote it to a general or personal rule only after enough testing.
7. Return quickly to a real reel so exercises serve production rather than replacing it.

This method complements the evidence-before-rule rule in Section 0.3. A single successful rooftop cut, for example, is evidence about that scene; it is not proof that every object reveal should use the same duration or that one cut position is universally best.

# 3. CURRENT PRODUCTION LOOP

Every reel should move through these departments in this order.

## 3.1 Story / intention
Define in one sentence:

- What is happening?
- What should the audience understand?
- What should the audience feel?
- What changes from the beginning to the end?

If the emotional/story change cannot be stated clearly, the visual plan will usually become random coverage.

## 3.2 Final-edit imagination
Before deciding camera angles, imagine the actual final sequence as if it is already playing in CapCut.

Questions:

- What is the first visible image?
- When does the audience receive new information?
- Where do cuts happen?
- Which reaction deserves screen time?
- Is the pace slow, accelerating, interrupted, or rhythmic?
- When should the scene become closer or wider?
- Where does silence or sound emphasis occur?
- What is the final image?

## 3.3 CapCut feasibility
For each intended final shot, answer:

- Is it a normal cut?
- Is it a speed change?
- Is it an overlay?
- Does it require masking?
- Does it require a clean plate?
- Does it require keyframing?
- Does it require motion tracking?
- Does it require background removal?
- Does it require an effect CapCut can reliably do?
- Does it require two separately timed performances?
- Does it require a camera movement that would break a simple mask composite?

If the construction method is unclear, simplify the shot before production.

## 3.4 Edit map
Build the final sequence by timecode before the storyboard.

Example:

| Time | Final image | Story job | Production method | CapCut method | Sound job |
|---|---|---|---|---|---|
| 0:00–0:02 | Wide, subject alone | Establish isolation/location | Locked 24mm wide | Normal cut | World ambience |
| 0:02–0:04 | B close-up | Warning | Separate B performance | Normal cut | Dialogue; ambience lowered |
| 0:04–0:05 | A reaction | Show impact | Separate A reaction | Normal cut | Breath / brief silence |
| 0:05–0:08 | A and B together | Confirm relationship | Locked plate + A pass + B pass | Overlay + mask | Matched room tone/dialogue |

The edit map answers: **What footage must exist for the final sequence to exist?**

## 3.5 Directing
Only after the edit map is clear should shot design begin.

Each shot must have a job such as:

- establish geography;
- show action;
- reveal information;
- show emotional reaction;
- change power relationship;
- create tension;
- isolate a character;
- show both characters' relationship;
- transition between spaces or states;
- provide an edit point.

An angle that only “looks cool” but adds no new information is optional, not required coverage.

## 3.6 Self-shooting plan
For each setup decide:

- tripod location;
- phone height;
- lens;
- approximate framing;
- body mark;
- eyeline mark;
- focus target;
- exposure target;
- white balance;
- recording start/stop method;
- wardrobe/prop state;
- guide dialogue method;
- number of takes;
- whether this is a full performance or insert only.

## 3.7 Performance
Performance is not only spoken dialogue. Capture:

- listening;
- thinking;
- eyes moving before the head;
- breath;
- hesitation;
- body tension;
- posture shifts;
- reactions after the other character's line;
- a usable hold before and after the action.

## 3.8 Sound
Sound is designed against the actual visual sequence, not as an isolated classroom exercise.

For every beat identify:

- **World:** where are we?
- **Action:** what physically happens?
- **Focus:** what sound should matter now?
- **Distance/perspective:** how near or far should it feel?
- **Rhythm:** what repeats?
- **Break:** what expected sound stops?
- **Contrast:** what changes between busy/quiet, near/far, soft/hard, normal/subjective?
- **Silence:** where should sound be reduced to focus attention?

## 3.9 Shoot order
Shoot order should optimize solo logistics, not blindly follow story chronology.

Group by:

- wardrobe/look;
- character;
- camera side;
- lighting condition;
- tripod setup;
- location area;
- composite setup.

## 3.10 Edit
The goal is to build the pre-imagined sequence, not to include footage merely because time was spent recording it.

During edit, record:

- footage that was missing;
- footage that was unnecessary;
- shots that did not cut together;
- continuity failures;
- performance mismatches;
- CapCut limitations;
- sound problems;
- pacing discoveries.

## 3.11 Review
Compare intention with final result. Then classify each issue as:

- idea/story;
- framing;
- camera height/lens/distance;
- blocking;
- eyeline/screen direction;
- exposure/focus/WB;
- continuity;
- acting;
- dialogue memory/cues;
- self-shooting logistics;
- CapCut construction;
- sound;
- location/heat/time;
- shot redundancy;
- missing coverage.

Then update this file.

# 4. SELF-SHOOTING KNOWLEDGE

## 4.1 The unique problem of filming yourself
When filming someone else, the camera operator can observe the subject live and adjust angle, body posture, hair, face, gestures, background, and light. When filming yourself, that feedback disappears while recording.

Therefore the solution is not to “guess the best angle.” The solution is to create a personal camera-reference system through screen tests and review.

## 4.2 Personal screen-test protocol
Use the same simple location and outfit so variables are controlled.

### Shot sizes to test
- environmental/full-body wide;
- medium-wide;
- medium;
- medium close-up;
- close-up.

### Horizontal angles to test
- front;
- left 3/4 (roughly 30–45°);
- right 3/4;
- profile.

### Camera heights to test
- eye level;
- slightly above eye level;
- slightly below eye level.

### Perspective/lens tests
- 24mm / main wide-normal perspective;
- longer / 2x perspective when space allows.

### Performance action inside every useful setup
Do not simply stand still. Record:

1. neutral;
2. look away;
3. move eyes toward an eyeline mark;
4. turn head;
5. think silently;
6. react;
7. speak one sentence;
8. use one natural hand gesture;
9. turn body;
10. settle and hold.

### Review categories
For each test evaluate:

- face perspective/distortion;
- jaw/cheek appearance;
- glasses reflections;
- hair silhouette;
- eye visibility;
- posture;
- shoulder angle;
- hand visibility;
- body language;
- background separation;
- light shape on face;
- whether the frame fits the emotion;
- whether the motion stays inside the crop;
- whether the shot cuts well with other sizes.

The result becomes a **Personal Camera Rules** section below. These rules must be based on actual footage, not generic beauty advice.

## 4.3 Current framing rule: distance comes after shot intention
Do not begin with “How many feet should the iPhone be from me?”

Correct decision order:

1. What information does the shot need to communicate?
2. Which shot size best communicates it?
3. Which lens/perspective is appropriate?
4. Place the iPhone at the physical distance needed to create that composition.

Examples:

- Environment + loneliness → wide.
- Body language + dialogue → medium/medium-wide.
- A realization in the eyes → close-up.

Distance is therefore a consequence of framing and lens, not the first creative decision.

## 4.4 Framing verification for a solo shoot
Until personal framing becomes intuitive, use a verification loop:

1. Put tape/marker where the body should be.
2. Frame using an object/stand at approximate head height if available.
3. Lock the tripod.
4. Record a 5–10 second test of yourself.
5. Return to phone and review the actual frame at full size.
6. Correct height/distance/subject mark.
7. Only then perform full takes.

This short test prevents many long wasted takes.

## 4.5 Personal Camera Rules — current status
**Status: not yet empirically mapped.**

Do not invent permanent claims such as “left 3/4 is best” until screen-test footage proves it.

# 5. TWO-PERSON / TWO-VERSION SOLO SCENES

## 5.1 Why this is a separate skill
A two-person scene creates problems that do not exist in a simple single-subject reel:

- shared screen geography;
- 180-degree line;
- matched eyelines;
- believable eye height;
- shot/reverse-shot relationship;
- reaction timing;
- continuity across separate performances;
- dialogue cue timing;
- wardrobe/character separation;
- clean plates;
- compositing/masking if both versions appear together.

Therefore two-person solo filmmaking should be trained progressively rather than treated as a normal first exercise.

## 5.2 180-degree line procedure
Before shooting:

1. Mark Character A's physical position.
2. Mark Character B's physical position.
3. Imagine/draw a straight line connecting A and B.
4. Pick one side of that line for the camera family.
5. Keep normal coverage on that side unless intentionally crossing the line with a motivated transition.
6. Mark eyeline targets at the height where the other character's eyes would realistically be.

Desired screen relationship in a simple conversation:

- A appears screen-left and looks toward screen-right.
- B appears screen-right and looks toward screen-left.

This makes the audience feel that they face each other even when recorded at different times.

## 5.3 Eyeline procedure when the second actor does not exist
Use a physical target:

- light stand;
- tripod extension;
- tape on wall;
- bottle/object placed at eye height;
- removable marker.

The marker should represent the other character's eyes, not merely their general direction. Record the height and position so the reverse angle can match.

## 5.4 Shot/reverse-shot first, same-frame composite later
Current learning priority:

1. Shoot A single.
2. Shoot B reverse single.
3. Match eyelines and screen direction.
4. Build dialogue and reactions with normal cuts.

This is easier and more controllable than trying to put both versions into one frame.

Only after shot/reverse-shot is reliable should the same-frame composite become a regular technique.

## 5.5 Locked same-frame composite procedure
If two versions of the same person must appear in the same frame:

1. Lock the tripod completely.
2. Lock exposure.
3. Lock focus.
4. Lock white balance.
5. Do not zoom or reframe between passes.
6. Record an empty clean plate for several seconds.
7. Perform Character A in one side of frame.
8. Keep the body, arms, clothing and shadows away from the intended mask boundary.
9. Perform Character B on the other side.
10. Preserve matching environmental light as much as possible.
11. In CapCut, place one performance above the other as an overlay.
12. Use a mask/split to reveal one side from each performance.
13. Feather only as much as needed; check the boundary for moving shadows or objects.
14. Use the clean plate if a repair is necessary.

### Current limitation
A moving camera makes this significantly harder because the mask boundary must track the camera movement and parallax. Therefore moving two-version composites are currently classified as advanced and should not be casually placed in a storyboard.

## 5.6 Over-the-shoulder problem
A true OTS needs an actual foreground body/shoulder. If one person is playing both characters, a normal reverse performance cannot magically create the missing foreground shoulder.

Options:

- use a stand-in person/object if available;
- shoot a deliberately “dirty single” with a foreground proxy;
- use separate foreground insert/overlay if technically justified;
- avoid OTS and use clean singles until the production value of OTS justifies the extra complexity.

Default beginner-solo choice: **clean singles over fake OTS.**

## 5.7 Continuity for two versions
Match:

- body position;
- torso angle;
- eye target;
- hand placement;
- sitting/standing height;
- emotional intensity;
- dialogue timing;
- pauses;
- direction of looks;
- prop state.

A believable conversation is built as much from matching listening and reactions as from spoken lines.

# 6. DIALOGUE AND PERFORMANCE SYSTEM

## 6.1 Problem discovered
Long dialogue + acting + directing + remembering eyelines + operating a solo setup created too much cognitive load.

This is not proof that dialogue scenes are impossible. It means memorization should not consume the attention needed for performance and technical accuracy while the workflow is still new.

## 6.2 Guide-track method
Before shooting, record the opposite character's dialogue as a simple guide track with intentional pauses.

When playing Character A:

- play Character B's guide track;
- listen to it;
- react naturally;
- deliver A's line;
- continue listening through the rest of the beat.

Then reverse for Character B.

Benefits:

- consistent timing;
- more natural reactions;
- less memorization pressure;
- easier matching between performances;
- better edit rhythm.

The guide track is temporary and can be replaced by the final clean dialogue in the edit.

## 6.3 Cue-card method
If a line is difficult, a short cue can be placed close to the eyeline target. The cue must not force obvious reading eye movement. Use keywords rather than full paragraphs where possible.

## 6.4 Full-performance coverage rule
For a major dialogue angle, perform the complete beat/scene rather than only the one line expected to appear in the edit.

Why:

- the editor may need a reaction before the line;
- a better take may occur in an unexpected place;
- timing can be changed later;
- listening reactions become available;
- continuity is easier to judge;
- cuts can move away from the speaker without creating a dead performance.

This does **not** mean every insert must contain the full scene. Detail inserts can be action-only.

## 6.5 Pre-roll and post-roll
For every dramatic take:

- record approximately 2–3 seconds before starting the action;
- remain in character for approximately 2–3 seconds after the line/action.

These handles are valuable for editing and sound transitions.

## 6.6 Emotional progression inside repeated questions
Do not deliver multiple questions at identical intensity. Example progression:

1. first question = confusion;
2. second = frustration begins;
3. third = personal/painful.

Emotion should evolve across the beat, otherwise cutting between angles will not create escalation.

# 7. COVERAGE SYSTEM

## 7.1 Shot-size job definitions
### Wide
Primary jobs:

- establish place;
- establish body relationship;
- establish isolation;
- show full movement/geography.

### Medium / medium-wide
Primary jobs:

- dialogue;
- body language;
- hand gestures;
- action with emotional readability.

### Close-up
Primary jobs:

- emotional shift;
- realization;
- reaction;
- highly important information.

### Detail / insert
Primary jobs:

- specific action;
- object information;
- transition;
- emphasis;
- edit bridge.

### Reaction
Primary jobs:

- show what the line/action did to the character;
- often more emotionally valuable than showing the speaker.

## 7.2 Non-redundancy rule
Do not shoot five angles simply because multiple angles are possible. Ask:

> What new information or emotional perspective does this setup add that the others do not?

If two shots do the same job, one may be unnecessary.

## 7.3 Camera movement rule
Movement should have a reason such as:

- reveal;
- follow action;
- increase pressure;
- release pressure;
- shift perspective;
- transition;
- show new spatial information.

Random movement added only to look “cinematic” can reduce clarity and complicate solo production/compositing.


## 7.3A Verified directing model — character, audience, and camera relationship
**Status: verified conceptual learning from 2026-09-13.**

Do not begin camera design by asking which movement looks cinematic. Separate two realities first:

- **Character experience:** What does the character want, know, not know, feel, decide, and physically do?
- **Audience experience:** What should the viewer know, notice, anticipate, discover, or feel while watching the character?

The character and audience do not have to feel the same thing. A character can be calm while the audience is afraid because the audience has information the character does not. Directing therefore manages both realities and controls when they align or diverge.

For current solo-reel planning, use this relationship:
- **Blocking = character ↔ physical scene.** Blocking describes the character's physical relationship with the space, people, and objects throughout the scene. Position/action/movement/stop are analysis tools for blocking, not its definition.
- **Camera = audience ↔ scene.** Camera placement, framing, and movement control how the audience visually relates to the character and physical world.

Do not reduce blocking to walking from Point A to Point B. Internal intention must become visible physical behavior. The same destination can produce different blocking depending on the character's response. Fear may create hesitation, listening and stops; irritation may create direct fast movement with little hesitation; curiosity may create measured investigation. Tempo and pauses are part of the physical journey. Do not decorate emotion with arbitrary gestures merely to signal it; let intention and situation choose believable behavior.

### Camera relationship vocabulary
Before choosing a named movement, decide the audience relationship needed for the beat:

- **WATCH:** Let the audience observe behavior/action within a deliberately designed frame. Actor movement does not require camera movement.
- **GO WITH:** Let the audience travel through a character's physical or dramatic journey with them. Following/tracking can serve this, but walking alone is not the reason.
- **REVEAL / REDIRECT:** Transfer audience attention to new information. This can also give the audience information the character does not have and create suspense.

These are audience relationships, **not three camera-movement techniques**.

### Verified camera-movement decision rule
**Actor movement ≠ camera movement.** A moving actor can be filmed by a static camera; a stationary actor can motivate camera movement; actor and camera can move together; or both can remain still.

Use this decision order:

1. What changed for the audience in this beat?
2. Should the audience WATCH, GO WITH, or have attention REVEALED/REDIRECTED?
3. Only then choose the camera technique that serves that relationship: static, pan/reframe, tracking/following, push-in/pull-out, etc.
4. Define why the camera movement starts.
5. Define what dramatic/informational/emotional arrival completes its job and allows the camera to settle or the edit to cut.

Camera movement should not stop merely because a predefined shot size was reached. A push-in can begin when a character's internal reaction becomes the important information and settle when the intended emotional transition has become readable. The framing change is the visible result of the audience-intention change.

Useful starting interpretations, not rigid formulas:

- attention moves across space/new information becomes important → pan/reframe or cut may serve it;
- audience should travel with a character → tracking/following may serve it;
- audience should become emotionally/psychologically closer to a moment → push-in may serve it even when the actor is still;
- no meaningful audience relationship needs to change → static may be stronger than adding movement.

### Static-frame planning lesson
If choosing WATCH for a continuous physical journey, know the blocking before placing the camera. Design enough usable frame space for the important start, path, stop, and destination rather than framing only the first attractive action and then being forced into an unplanned pan/zoom/reframe. Static does **not** automatically mean wide; shot size follows how much story information and physical journey the frame needs to contain.

### Current learning boundary
Akshay already understands the mechanical distinction between a physical push-in and a zoom-in. Do not spend future lessons reteaching their basic definitions unless a practical misunderstanding appears. The current skill gap is purposeful selection and coordination of actor blocking with camera behavior, especially inside continuous shots.

## 7.4 Take-count working rule
Current default for a normal setup:

- get one technically correct take;
- get a second strong performance/continuity take;
- add a third only when the beat is critical or a specific improvement is being attempted.

Do not accumulate endless safety takes without knowing what is being changed.

# 8. EDITING-AS-PREPRODUCTION

## 8.1 Editing must influence the storyboard
A storyboard is incomplete unless each shot has a post-production path.

For every shot, include:

- final duration estimate;
- entry cut;
- exit cut;
- required source footage;
- whether full performance is needed;
- whether a reaction must be captured;
- CapCut operation;
- sound transition.

## 8.2 Pacing and cut-point model — current working system
Do not treat shot duration as a preset based on shot size. A wide is not automatically long and a close-up is not automatically short. Screen time follows the job of the shot and what is still developing inside it.

When judging a shot, separate three clocks:

- **Action clock:** how the physical action develops.
- **Audience-understanding clock:** when the viewer has received the necessary information.
- **Emotional clock:** how long a thought/reaction needs to become readable or felt.

A useful editing question is: **At what frame has this shot completed the job I need from it?** If the audience already understands the information and nothing new is developing, extra frames may create drag. If emotion, reaction, anticipation, or action is still developing, the hold may be justified.

### Raw duration is not final duration
Long self-shot takes are useful because they provide handles and performance options. They do not imply that the final edit should preserve the full recorded action. Enter the useful part late enough to avoid dead time and leave when the intended information/action/emotion is complete.

### Information versus reaction
A simple object insert may communicate its job quickly, while a human reaction can deserve more time because the viewer must read a developing internal response. This is a working principle, not a fixed duration formula. If the object itself contains story information that must be studied, its hold can be longer.

### Cut position inside movement
Do not ask only how many seconds a clip lasts. Identify which phase of movement the audience should experience before the cut. A performance can contain:

**rest → eyes move → head/body starts → active movement → arrival → hold**

A cut can occur before movement, during movement, on arrival, or after a hold. Each creates a different relationship with the next shot. Cutting during action can carry visual energy across the edit; cutting early can create a question that the next shot answers; cutting after completion can feel more settled or deliberate. None is universally correct.

### Entry and exit are separate decisions
The exit frame of Shot A and the entry frame of Shot B jointly create the cut. Therefore a useful edit map should not record only estimated duration; it should describe the intended action/performance state at both boundaries when that matters.

### Controlled-variant review
When a cut is uncertain, duplicate the edit and alter one boundary or timing variable at a time. Compare variants without changing music, effects, grading, or unrelated shots when those would contaminate the test. Personal preference and the intended story feeling are valid evidence; disagreement between two reviewers should trigger analysis of what each version communicates rather than automatic obedience to either reviewer.

## 8.3 CapCut-construction categories
Classify each planned shot as:

### Easy
- normal cut;
- simple speed change;
- crop/reframe;
- basic keyframe movement;
- simple audio layering;
- simple color adjustment/LUT workflow.

### Medium
- overlay;
- static mask composite;
- simple background removal;
- controlled keyframe animation;
- timed split-screen;
- more precise sync.

### Advanced / currently expensive in time
- moving same-person composite;
- complex occlusion across mask boundaries;
- multi-layer rotoscoping;
- precise tracking under changing perspective;
- interactions where one version passes in front of/behind the other;
- effects whose success cannot be previewed or tested quickly.

The production plan should match the current desired learning difficulty. A reel can include one “stretch” technique, but should not make every shot a stretch technique.

## 8.4 Backup-version rule
For any difficult shot, define a simpler fallback before going to location.

Example:

- Desired: both versions in one moving two-shot.
- Backup: locked two-version composite.
- Safer backup: shot/reverse-shot singles.

This prevents a location session from collapsing when the hardest technique fails.

# 9. SOUND INTEGRATION

## 9.1 Current sound-learning position
Sound learning remains important. It should not be abandoned. The new realization is that sound practice needs usable visuals so the learner can understand where and why the sound changes the scene.

## 9.2 Existing principles that should be integrated
### World / Action / Focus
- World = where we are.
- Action = what physically happens.
- Focus = what matters to the audience now.

### Distance is perspective
A sound's narrative importance is not defined only by physical loudness or distance. A far sound can be foreground if the film emphasizes it.

### Rhythm and break
Repeated sound creates expectation. Breaking the pattern can signal arrival, danger, change, or attention.

### Contrast and expectation
Busy → quiet, near → far, continuous → stopped, or normal → subjective sound can create narrative meaning.

### Silence / reduction
Silence is rarely literal absence of all sound. Often it means removing or reducing expected layers so one important element becomes noticeable.

## 9.3 Sound-planning question for every edit row
Ask:

1. What is the base world ambience?
2. Which physical action needs a synchronized sound?
3. What should the audience notice most in this beat?
4. Should the sound perspective be objective or subjective?
5. Is there a rhythm that should continue?
6. Should that rhythm break?
7. Is music needed, and if so, what job is it doing?

# 10. DIFFICULTY LADDER FOR SOLO FILMMAKING

This ladder prevents a simple learning project from accidentally becoming a multi-department advanced production.

## Level 1 — Single actor, controlled action
- one location;
- one simple action;
- three meaningful shots;
- 5–10 second completed edit;
- no complex compositing.

Goal: framing, self-marking, basic coverage, cutability.

## Level 2 — Single actor + short performance/dialogue
Goal: facial performance, audio, cueing, reactions, continuity.

## Level 3 — Single actor + movement/blocking
Goal: marks, action continuity, focus/framing under movement, matched coverage.

## Level 4 — Two-character scene via shot/reverse-shot
Same actor can play both roles, but no same-frame composite is required.

Goal: 180° line, eyelines, timing, guide tracks, performance matching.

## Level 5 — Two versions in one locked frame
Goal: clean plate, static mask composite, boundary discipline, matched light.

## Level 6 — Advanced multi-version scene
Possible elements:

- camera motion;
- foreground crossings;
- occlusion;
- interaction;
- moving mask/tracking;
- advanced sound perspective.

Do not enter Level 6 simply because the story idea is exciting. Build the technique first or create a simpler visual grammar.

# 11. FAILURE / EVIDENCE LOG

## Evidence E001 — Two-character gym production overload
**Date:** 2026-09-04  
**Observed:** A simple few-second two-person subconscious scene took about 1.5 hours and still felt unsuccessful. Heat and repeated setup changes increased cognitive fatigue.  
**Important interpretation:** The issue was not lack of effort. Too many unresolved technical and performance variables were active at once.  
**Current verified system response:** Work backward from edit; reduce simultaneous difficulty; use marks, guide tracks, screen-direction planning, and progressive difficulty.

## Evidence E002 — iPhone distance became confusing
**Observed:** The question “how far should the iPhone be?” did not have a useful answer by itself.  
**Correction:** Start with the story information and shot size; physical distance follows framing and lens.

## Evidence E003 — Two-person perception was unclear
**Observed:** It was difficult to know how two separately performed characters should appear to look at each other.  
**System response:** establish A/B marks, eyeline targets, eye height, and 180° line before coverage.

## Evidence E004 — Dialogue memory overloaded production
**Observed:** Remembering dialogue while self-directing made the shoot harder.  
**System response:** prerecorded opposite-character guide tracks and/or near-eyeline cue keywords; major coverage still gets the full performance beat.

## Evidence E005 — Storyboard alone was insufficient
**Observed:** Imagining a shot did not guarantee that it could be reproduced in post-production.  
**System response:** edit map and CapCut construction method must exist before the production storyboard is considered ready.

## Evidence E006 — Isolated sound training felt hard to apply
**Observed:** Sound concepts were understood, but without good visuals it was difficult to practice where and why to apply them.  
**System response:** build small finished visual projects and integrate sound into them rather than isolating sound indefinitely.

## Evidence E007 — Rooftop LOOK → OBJECT → REACTION pacing test
**Date:** 2026-09-05  
**Observed:** A tiny rooftop scene was shot as movement/geography → attention change → plant reveal → reaction. In the first edit, the plant reveal was held longer while the reaction was shorter. A second independent edit shortened the plant and allowed more reaction time, and the sequence communicated more efficiently.  
**Interpretation:** The useful discovery was not a universal duration number. The plant's simple information completed quickly, while the facial reaction continued developing.  
**Current status:** Observed evidence supporting the pacing model in Section 8.2. Do not promote the specific durations to a general rule.

## Evidence E008 — Cut-point variants changed perceived movement
**Date:** 2026-09-05  
**Observed:** Multiple variants changed the exit point around the walking/attention/head-turn beat. Akshay preferred the first variant because it preserved more of the movement he wanted the audience to experience; another review preferred a different variant.  
**Interpretation:** Equal or similar durations can contain different amounts of useful action/story. Reviewer disagreement can reveal different intended emphasis rather than a single objectively correct cut.  
**Current status:** Evidence supporting controlled cut-point testing; no universal personal cut preference has been established.

# 14. NEW REEL INTAKE PROTOCOL

When Akshay says, “I have a reel idea,” process it through the following intake.

## 14.1 Story core
- What happens?
- What changes?
- What should the audience feel?
- What is the final payoff/image?

## 14.2 Constraints
- target duration;
- location;
- available time;
- heat/noise/crowd limits;
- lighting;
- solo or helper available;
- wardrobe;
- iPhone/tripod/other gear;
- CapCut-only or other software;
- dialogue/music requirements.

## 14.3 Final edit map
Create timecoded beats first.

For every beat include:

- final frame;
- shot size;
- emotion/story job;
- action/dialogue;
- estimated length;
- production source;
- CapCut technique;
- sound plan;
- difficulty rating.

## 14.4 Feasibility gate
For every planned shot ask:

- Can it be shot solo?
- Can framing be verified before full takes?
- Is the eyeline physically markable?
- Can focus/exposure be locked?
- Can CapCut build the intended result?
- Does it require an advanced composite?
- Is there a fallback?

## 14.5 Storyboard
Only now create storyboard frames/diagrams.

The storyboard should show or state:

- exact final crop;
- subject placement;
- camera side;
- eyeline;
- movement;
- lens;
- camera height;
- emotional intention;
- edit connection to previous/next shot.

## 14.6 Shoot order
Reorder for efficiency:

- all Real-world look;
- all Character A;
- all Character B;
- same tripod setups together;
- same light state together;
- inserts/plates last if practical.

## 14.7 Take plan
For every setup specify:

- full beat vs insert;
- target number of strong takes;
- what is intentionally changed between Take 1 and Take 2;
- continuity notes.

## 14.8 Post-shoot review
After footage is available, answer:

- What did we intend?
- What actually happened?
- Which specific frame worked?
- Which setup cost too much time?
- What was impossible to edit?
- What shot was missing?
- What shot was unnecessary?
- What personal camera rule did we learn?
- What CapCut rule did we learn?
- What sound rule did we learn?
- What should be changed in this KB?
